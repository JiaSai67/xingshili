# 專屬計畫書 🌸

專為寶貝專屬打造的馬卡龍粉色系每日計畫與打卡清單工具。支援樹狀多層任務、打卡狀態即時切換、自訂字體與透明度微調、清單匯入與匯出等豐富功能。

## 系統需求
- Windows 10 / 11
- Python 3.9 以上版本

## 安裝與執行方法

本專案完全符合 **AI Tool Launcher** 開發規範，支援隨插即用與自動化環境建置。

1. **一鍵註冊與安裝**
   將專案下載或 `git clone` 至本地後，直接雙擊執行目錄下的 `linkme.bat`。
   這會將本工具註冊至你的 AI Tool Launcher 啟動器中。

2. **啟動程式**
   打開你的 AI Tool Launcher，在工具清單中找到「**專屬計畫書 🌸**」並點擊啟動。
   啟動器會**自動幫你安裝** `requirements.txt` 中所需的所有依賴套件（如 `PyQt6`），完全不需要手動下達任何 `pip install` 指令！

3. **自動更新**
   當 GitHub 有新版本時，只需在啟動器點擊「🔄 重新拉取」，啟動器即會自動執行更新與環境同步。

## 功能特色
- 🌸 **馬卡龍粉嫩主題**：溫馨療癒的視覺風格與貓咪爪印打卡互動。
- 📋 **樹狀多層打卡清單**：支援無限層級子任務建立、折疊與展開。
- 💖 **分類與我的最愛**：側邊欄快速切換與自訂分類管理。
- 🔤 **自訂字體與尺寸微調**：支援外掛 `.otf`/`.ttf` 字體（如 Terrarum Sans Bitmap），並能獨立微調各區塊文字大小。
- 💾 **即時儲存與匯入匯出**：所有編輯自動持久化保存，並支援單獨專案 JSON 檔案匯出與匯入分享。

## 專案結構
- `main.py` - 主程式入口
- `planner_app.py` - 計畫書主視窗與核心互動邏輯
- `config.py` - 設定與資源路徑管理、色彩與字體配置
- `components/` - 自訂 UI 元件（分類、任務卡片、標籤、按鈕等）
- `assets/` - 圖示與背景資源
- `data/` - 資料庫與預設模板清單
- `fonts/` - 自訂字體資源
- `linkme.bat` - AI Tool Launcher 註冊腳本
- `requirements.txt` - Python 套件相依清單
